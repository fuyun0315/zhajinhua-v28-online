# V28 炸金花多人联网网页版（第一版测试原型）

## 这个项目是什么
- `v28_reference/zhajinhua_v28_bet_log_enhanced.html`：你原有的 V28 HTML 源文件，完整保留作基准。
- `server.js`：多人房间和服务端游戏状态；支持创建/加入6位房间、最多6人、服务器发牌、跟注、加注、弃牌、比牌和虚拟筹码结算。
- `public/`：适配手机的联网网页界面。

**请注意：** 为了先建立稳定的联网链路，本项目目前采用与 V28 牌型顺序一致的轻量联网界面，并非已经把 V28 原版的所有动画、音效、托管、倒计时逐行合并进来。原版已放在参考目录，下一阶段再逐项迁移。此版仅虚拟筹码，无充值、提现或真钱功能；服务器重启后，内存房间会清空。

## 你只有安卓手机：部署网页版的办法
你需要一个 GitHub 账号和一个可运行 Node.js Web Service 的云平台账号。云平台网页界面可能随时间变化。

### 第一步：上传项目到 GitHub
1. 手机浏览器打开 `https://github.com`，登录后新建一个空仓库，例如 `zhajinhua-v28-online-web`。
2. 在手机文件管理器里解压本 ZIP。
3. 将解压后的项目文件上传到仓库根目录，确保根目录能看到 `package.json`、`server.js`、`render.yaml`、`public` 和 `v28_reference`。
4. 若手机浏览器上传多个文件不方便，可以在浏览器菜单里切换“桌面版网站”。

### 第二步：部署服务器
1. 手机浏览器打开 `https://render.com` 并登录。
2. 新建 Web Service，连接你刚才的 GitHub 仓库。
3. Build Command 填 `npm install`；Start Command 填 `npm start`。
4. 部署成功后平台会给一个 HTTPS 地址。打开地址，应看到“炸金花 V28”联网测试页面。

### 第三步：用两部手机测试
1. 手机 A 打开部署网址，输入昵称，点击“创建房间”。
2. 把屏幕上的6位房间号发给手机 B。
3. 手机 B 打开同一网址，输入昵称和房间号，点击“加入房间”。
4. 房主点击“房主开始新一局”。
5. 轮到自己时可以跟注、加注、比牌或弃牌。每位玩家的手牌只发送给本人；服务器负责发牌和比牌判定。

## 当前限制和下一步
- 第一版没有用户账号系统，昵称只用于本次房间。
- 暂不支持断线重连、旁观、聊天、音效、V28原版托管/计时器与全部动画。
- 目前每次操作后轮到下一位；完整多轮下注/结算规则还需按你的 V28 规则继续补全测试。
- 不要用于真实货币或有价筹码交易。
- 多人网页稳定后，再把它封装成 APK；APK 只是网页外壳，服务器必须持续在线。
