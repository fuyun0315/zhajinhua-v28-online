# 炸金花 V39 联网对战版

V39 基于 V38 源码增量升级，保留原有游戏逻辑，新增看牌标识、本局累计投入、房间每局初始投入自定义和模拟充值。

## 本地运行

需要 Node.js 18 或更新版本。

```bash
npm install
npm run check
npm test
npm start
```

打开 `http://localhost:3000`。

## Railway 部署注意事项

- Start Command：`npm start`（通常可自动识别）。
- 为持久化账号、积分和充值记录，创建 Volume，并将 `DATA_FILE` 设置为挂载路径下的文件，例如 `/data/game-data.json`。
- 设置独立的 `SESSION_SECRET`，不要使用公开或默认密钥。
- `/health` 可用于确认服务运行状态和版本。

## V39 功能

- 玩家看牌后头像处显示“已看牌”。
- 每位玩家头像处显示本局累计投入。
- 创建房间时可设置每位玩家每局初始投入（1–100,000）。
- 模拟充值（1–1,000,000），记录流水，防止同一请求重复到账，不涉及真实支付。
- 牌局中充值不会立即修改当前手牌局的筹码；充值储备在下一局开始时并入筹码。
- 原有 V38 的下注基准、托管、机器人、牌局结算和未匹配投入退款逻辑尽量保持不变。

## 重要说明

本项目使用 JSON 文件保存账户与充值流水；部署时必须正确配置持久化存储。自动化测试通过不等于已经在 Railway 或真实手机设备完成完整验收。
